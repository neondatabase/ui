Every team building an agent platform on Neon ends up writing the same UI. An auth card. A model picker. A sandbox preview with a wake button. A usage panel over consumption metrics. Neon UI is a shadcn registry with all of it, ready to install:

<InstallationCommand command="npx shadcn@latest add https://ui.neon.com/r/auth-form.json" />

The component source lands in your project. It's your code from that point on.

<Callout type="note">
  Neon UI is under active development. Components land in milestones; watch the
  [repository](https://github.com/neondatabase/ui) for releases.
</Callout>
