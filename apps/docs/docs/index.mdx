Every team building on Neon ends up writing the same UI. A branch picker. A connection string card with a copy button. A usage meter. A file dropzone wired to Neon Storage. Neon UI is a shadcn registry with all of it, ready to install:

```bash
npx shadcn@latest add https://ui.neon.com/r/branch-picker.json
```

The component source lands in your project. It's your code from that point on.

:::note Neon UI is under active development. Components land in milestones; watch the [changelog](/changelog) for releases. :::

## Categories

- **Brand** — NeonAurora, SQLConfetti
- **Database** — BranchTree, BranchPicker, BranchDiff, SchemaExplorer, SQLRunner, QueryHistory
- **Storage** — FileDropzone, FileBrowser
- **Infrastructure** — ComputeStatus, AutoscaleChart, ConnectionCard, UsageCard, HealthCard, LogsViewer
- **AI** — ModelPicker, PromptPlayground, CostMeter, TokenGraph
- **Authentication** — SessionList, ApiKeyList, OrganizationSwitcher
- **Dashboard** — ActivityFeed, MetricCard, CommandPalette
