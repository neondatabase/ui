`ToolCallChip` shows one tool invocation in an agent turn: a spinner with a softly breathing name while it runs, a springy swap to a green wrench on completion, an alert on error. The name renders in mono, with an optional `detail` (file path, command) that truncates first when space is tight. [AgentChat](/agent/agent-chat) maps AI SDK tool parts onto these automatically.

## Install

<InstallationCommand command="npx shadcn@latest add https://ui.neon.com/r/tool-call-chip.json" />

## Usage

```tsx
import { ToolCallChip } from "@/components/neon-ui/tool-call-chip";

<ToolCallChip name="writeFile" state="running" />;
```

## Wiring to Neon

Map AI SDK tool parts (from `message.parts`) onto chips: `output-available` → done, `output-error` → error, anything else → running. The typed example shows the full mapping for both static and dynamic tool parts.

## Accessibility

- The chip is plain text with an icon, announced as one phrase: the tool name and its state.
- Running state exposes `role="status"`, so completion is announced without stealing focus.
- The spinner-to-wrench swap is conveyed by the status text, not color alone.
- Spinner rotation is static under `prefers-reduced-motion`.
